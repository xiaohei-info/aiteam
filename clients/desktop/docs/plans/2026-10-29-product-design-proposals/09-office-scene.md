# 9. 办公室：休息点姿势与朝向、开关门、开会状态

> 视觉方向沿用已定规则：**俯视，带一点点立体**；常驻工位的 3/4 视角是例外，不改。员工复用 AIFred 的 chibi Spine 资源。

## 9.2 休息点：姿势与朝向

### 数据：活动点增加三个字段

```ts
interface MapSpot {
  // …现有字段
  kind: 'restroom' | 'pantry' | 'meeting' | 'corridor' | 'lounge' | 'custom'   // 新增 lounge
  /** 到达后的朝向；'auto' = 面向 faceTarget 或最近的阻挡家具 */
  facing?: 'front' | 'back' | 'left' | 'right' | 'auto'
  /** 到达后的姿势 */
  pose?: 'stand' | 'sit' | 'lean'
  /** 面向的地图元素（咖啡机、沙发前的茶几、窗户） */
  faceTarget?: string
  /** 同时可容纳几人；满了就不再作为目的地，避免叠人 */
  capacity?: number
}
```

旧地图没有这些字段时：`facing` 按 `auto` 处理，`pose` 按 `stand` 处理，行为和现在一致。

### 姿势怎么表现（需要决定）

| 方案 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| **A（推荐）家具遮挡** | 与工位椅同样的做法：员工站到沙发、扶手椅的座位点上，家具的靠背和扶手图层画在员工上面，遮住下半身；角色整体下移 6px，看起来「陷进」座位 | 不需要新动画；和工位风格一致；马上能做 | 只适合有靠背或扶手的家具；侧面沙发效果一般 |
| B 新增 Spine 坐姿动画 | 美术新做 `movement/sit-{4 方向}` | 最自然；任何位置都能坐 | 需要美术排期；9 套皮肤都要验证 |
| C 只用表情 | 不表现坐，站着播放休息表情 | 最简单 | 看不出在休息 |

推荐 **A**，B 作为后续美术升级。`lean`（倚靠）同样用 A 的思路：站在柜台、窗台边，朝向柜台。

### 各类活动点的默认行为

| 活动点 | 姿势 | 朝向 | 停留 | 到达后的表现 |
|---|---|---|---|---|
| 茶水间 · 咖啡机 | lean | 面向咖啡机 | 8–15 秒 | 先 `idle`，3 秒后播一次 `emotes/just-right`（喝到咖啡） |
| 休息区 · 沙发 | sit | 面向茶几 | 20–40 秒 | `idle`，偶尔 `emotes/laugh` |
| 休息区 · 扶手椅 | sit | 面向茶几或窗户 | 20–40 秒 | 同上 |
| 窗边 / 绿植 | stand | 面向窗外或绿植 | 10–20 秒 | `idle`，偶尔 `emotes/thinking` |
| 过道 | stand | 有同伴时面对面，否则保持行走方向 | 5–10 秒 | 两人同时在 48px 内时互相转向并交替播 `emotes/wave` 一次（「打招呼」） |
| 厕所 | — | — | 现状 | 进入后隐藏（关门，见 9.3） |

朝向计算：`auto` 时用 `facingFromDelta(target - stand)`；有同伴时优先面对同伴。

### 编辑器

活动点属性面板增加：类型下拉里加「休息区」、朝向（4 个方向按钮 + 自动）、姿势、容量、面向目标（在画布上点选元素）。选中活动点时在画布上画一个小扇形箭头表示朝向，一个小图标表示姿势。

### 地图

默认 10 人办公室地图增加一个休息区（例如右下角入口附近）：一张三人沙发、两把扶手椅、一张圆茶几、一盏落地灯，`sofa-top`、`armchair-top`、`coffee-table-top`、`floor-lamp-top`、`rug-round-top` 都是现有素材。

## 9.3 开关门

### 数据

门图元增加一段门的配置：

```ts
interface MapDoor {
  roomId?: string                     // 属于哪个房间
  orientation: 'up' | 'down' | 'left' | 'right'
  hinge: 'start' | 'end'              // 门轴在哪一侧
  mode: 'auto' | 'open' | 'closed'    // 自动 / 常开 / 常闭
}
```

### 状态与规则

| 状态 | 触发 | 表现 |
|---|---|---|
| 关闭 | 默认（`auto` 模式没人靠近时） | 门扇贴合墙洞 |
| 打开 | 有员工走到门口 48px 内且路径要穿过门 | 门扇绕门轴 0→90° 旋转，160ms，`ease-out` |
| 自动关闭 | 最后一个人离开门口 1.2 秒后 | 90→0°，200ms |
| 会议中 | 会议室全员入座后 | 关闭，门把手位置显示一个 6px 红点；不再因有人靠近而打开（非成员本来就不会进入使用中的房间） |
| 有人（厕所） | 有员工在厕所内 | 关闭 + 红点；其他员工选厕所为目的地时排队等候或改去别处 |
| 常开 / 常闭 | 编辑器里设置 | 固定状态；常闭的门对寻路来说是墙 |

寻路：`auto` 模式的门不阻挡寻路（会自动打开）；会议中和有人的门对非相关员工视为阻挡。

### 美术资源（需要新做）

现有只有三张「已打开」贴图。需要按俯视轻立体风格补：
- `door-leaf-{up,down,left,right}.png`：单独的门扇（用于旋转），宽度与墙洞一致，厚度 6–8px，带轻微接触阴影。
- 门洞（门框）沿用墙体素材，与门扇分离，满足「墙面连续无缝」的已定要求。
- `reduce-motion`（系统减少动态效果）开启时：不旋转，直接切换开 / 关两张贴图。

## 9.4 开会状态

### 前置：打开会议开关

`meetingsEnabled` 当前是关闭的。需要先确认：是因为之前效果不好关掉的，还是另有原因。下面的设计假设重新打开。

### 会议的三个阶段

| 阶段 | 触发 | 房间 | 员工 | 门 |
|---|---|---|---|---|
| **召集中** | 群聊里同时 ≥3 位员工在协作 | 房间上方徽标「召集中 2/4」，玻璃隔断描金色细边 | 成员从工位起身，走向会议室；已到的人在座位上面向桌子，`idle` | 打开 |
| **会议中** | 全员入座 | 徽标「会议中 · 群名 · 03:12」（计时）；玻璃隔断加一层淡金色透明遮罩（12%） | **正在回复的员工**：现有 `talking` 动作（`SpineCharacter.playTalking`）+ 头顶小气泡显示「发言中」；**被 @ 正在思考的员工**：现有 `thinking` 动作；其他人 `idle` 面向发言人 | 关闭 + 红点 |
| **散会** | 所有 @ 结束并等待 `lingerMs` 后 | 徽标变成「已结束」，1 秒后淡出 | 依次起身，走回工位 | 打开，最后一人离开后自动关闭 |

「面向发言人」：入座后默认面向会议桌中心（现有逻辑）；发言人变化时，非发言成员在原座位上转向发言人（只能 4 个方向，取最接近的）。

### 交互

- 点击会议室徽标：打开对应的群聊。
- 悬停徽标：显示成员头像列表和会议主题（群名）。
- 办公室底部的活动记录增加条目：「10:21 会议室 A：Q4 复盘群开会（4 人）」「10:35 散会，用时 14 分钟」。

### 会议室不够时

全部会议室都在使用中：成员聚到发起人工位旁站成一圈（复用串门的站位逻辑，扩展成多人），不显示房间徽标，在发起人头顶显示「临时讨论 · 群名」。

## 9.5 视觉规范

| 元素 | 规范 |
|---|---|
| 房间徽标 | 高 22px 药丸；`--surface-1-glass` + 毛玻璃；左侧 6px 状态点：召集中 `--warning`、会议中 `--danger`、已结束 `--text-muted`；文字 11px |
| 计时 | `font-number`，`--text-gold` |
| 会议中遮罩 | 房间矩形，`rgba(212,175,55,0.12)`，边框 1px `rgba(212,175,55,0.45)` |
| 发言气泡 | 复用现有员工气泡（`EmployeeBubble`），内容「发言中」或该员工本轮回复的前 12 个字 |
| 门红点 | 直径 6px，`--danger`，外圈 2px 白色 30% 透明 |
| 动效 | 门 160–200ms；徽标出现 / 消失 200ms 淡入淡出；`prefers-reduced-motion` 时全部改为直接切换 |

## 9.6 实施顺序建议

1. 活动点朝向 + `lounge` 类型 + 默认地图休息区（只改数据和场景逻辑，不需要新素材）。
2. 开会状态：打开开关、徽标三阶段、发言人表现。
3. 开关门（需要先完成门扇素材）。
4. Spine 坐姿动画（可选，美术排期）。

## 9.7 验收标准

1. 员工到达茶水间、休息区后朝向正确，不再背对目标物。
2. 沙发上的员工下半身被沙发靠背遮住，头部完整可见。
3. 同一个活动点超过容量时，后来的员工改去别处。
4. 门在有人通过时打开、离开后关闭；会议中和厕所有人时保持关闭并显示红点。
5. 会议三阶段的徽标、计时、发言人表现正确；点击徽标能打开群聊。
6. 开启「减少动态效果」时没有旋转和淡入淡出。
