# 登录退出排查记录

日期：2026-09-11

## 已确认的代码行为

- 原事件流（SSE）收到单次 401 会直接清除登录；普通 HTTP 请求则会先用 whoami 复核。因此 SSE 存在比普通接口更容易误退的路径。现已统一为复核当前凭证确实失效后才退出；未确认、网络失败及旧凭证响应继续退避重连。
- 凭证 exp 距到期不足 30 秒时，客户端会主动退出或拒绝恢复。这是现有有效期策略，当前契约未提供刷新凭证接口，本次未延长凭证有效期。
- 启动恢复需要读取系统凭证库、验证本机身份并同步授权。任何阶段失败均可能显示登录页；验证或同步失败时保留系统凭证，可点击重试恢复，不需要据此认定密码失效。
- 登录后的过期检查改为使用 whoami 已验证的 claims，与随后保存及定时退出使用的数据一致。

尚无历史退出原因日志，无法将用户此前发生的每次退出归因于其中某一条；本次修复的是已确认存在的误退路径。

## 新增日志

登录页展开「登录状态诊断记录」可选中复制。最近 100 条保存在当前 WebView 的 `aifred.auth-diagnostics.v1`，退出不会删除；存储不可用时退回内存，不能保证跨重启保留。

只记录时间、固定原因和来源、HTTP 状态码、身份复核结果、剩余有效秒数。禁止写入账号、用户 ID、租户 ID、密码、Token、请求正文及错误原文。

| 原因 | 含义 |
| --- | --- |
| token_expired / restore_expired | 定时到期 / 恢复时已到有效期边界 |
| http_unauthorized / sse_unauthorized | 普通请求 / 事件流确认凭证失效 |
| http_unauthorized_ignored / sse_unauthorized_ignored | 401 未导致退出 |
| restore_vault_failed | 系统凭证库读取失败 |
| restore_missing / restore_invalid | 凭证缺失 / 已存内容无法解析 |
| restore_identity_failed | 本机身份验证失败 |
| restore_sync_failed | 用户授权同步或就绪检查失败 |
| user_logout / reauthentication | 手动退出 / 开始重新登录 |
| credential_delete_failed | 退出时凭证清理失败 |
| login_succeeded / session_restored | 登录 / 恢复成功，可结合剩余有效期定位固定时长退出 |

下一次复现时保留退出前后的日志即可区分到期、服务拒绝、同步失败和凭证库问题。
