# 本地目录知识库实施计划

依据 `local-directory-knowledge-design.md`，后端基线为 FredServer main `21684254`，功能分支 `feat/local-directory-knowledge`。

> 2026-10-19：本计划已按下文实施并合入 FredServer main（`fa16025c`）。它假设会话在本机 Agent 执行，而当前会话在远端执行，所以第 5 条的会话工具在当前架构下不生效。后续实施以[方案文档](2026-10-19-local-directory-remote-session-gap.md)第 6–9 节为准。和本计划不同的地方：完全访问模式也可以检索（第 5 条）；片段和 @ 的文件会保存在远端对话记录里，本机仍不保存正文（第 2 条）；群聊改为 @文件。

## 边界与顺序

1. 原生宿主提供 Unix socket 授权通道（私有目录/0600），显式传给 Agent。成员身份由 Agent 的正式 JWT 验证得出；开发认证不开放此能力。原生选择产生短期一次性登记票据，Agent 消费时绑定已验证身份。宿主不可用默认拒绝。
2. Agent 新增 SQLite 成员目录资源和员工绑定，严格 tenant/member 所有权、真实员工投影及快照匹配，乐观版本控制；撤销操作不依赖员工可执行性。资源正文不持久化。
3. macOS 原生安全读取使用目录文件描述符逐级 openat/O_NOFOLLOW，限制类型、大小和读取预算，验证根目录及文件身份和读取前后版本；未支持平台关闭。纯文本首发，DOCX 在独立安全验证通过前保持禁用。
4. 关键词检索和会话内随机引用支持中文、多关键词、稳定排序、Unicode 码点分页、预算与部分覆盖；每批和交付前重新鉴权。
5. 接入 SessionHost 专用工具、每轮能力刷新及受控来源接口。普通工具不扩大目录范围；实际验证沙箱对源目录和受保护状态的隔离，失败关闭能力。自动化和 full-access 禁用。
6. 桌面本地文档页及员工工作台接入目录登记/绑定，清晰说明扫描与检索差异和远程模型的数据流。来源只通过实际执行记录验证，点击重新鉴权。
7. 补齐 OpenAPI/桌面契约、测试和交付记录。构建并导入 Agent 包；源码检查、模拟宿主/模型测试、实机权限/模型行为和安装包验证分别报告。

## 验证

- 宿主协议：缺失配置/连接断开/错误凭据/重复消费/身份不符/授权变化均拒绝。
- 权限：跨租户、成员、员工、会话、轮次；显式空/拒绝/畸形工具策略；注销与撤权失效。
- 文件：链接、中间目录替换、根身份漂移、路径前缀碰撞、FIFO、变化中内容、UTF-8、预算。
- 检索：中文独有事实、多关键词、文件名/正文评分、部分覆盖、来源版本和偏移。
- 回归：Agent TypeScript/相关测试、Rust 测试、桌面类型检查/构建/契约审计；独立记录无法执行的实机验收。
