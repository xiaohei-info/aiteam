# AIFred 设计系统视觉规范

> 来源：`docs/design/设计视觉系统参考.html`
> 适用范围：后续所有项目 UI 新建、改版、视觉走查与 PR Review。
> 落地原则：参考页定义视觉方向，代码实现优先使用 `src/styles/globals.css` 与 `tailwind.config.ts` 中已有 token。

## 1. 视觉定位

AIFred 的默认视觉语言为 **黑金质感 + 深色沉浸 + 毛玻璃层次 + 企业级精致感**。界面应该像一套高端办公工具：克制、清晰、有层次，不做营销页式的大装饰，也不做廉价的单色深色面板。

核心关键词：

- **Black & Gold**：极夜黑承载界面，流光金负责品牌、选中态、主操作和关键数值。
- **Glassmorphism**：用半透明背景、模糊、细边框和高光制造层级。
- **Operational UI**：SaaS/办公产品优先信息密度、扫描效率和稳定布局。
- **Premium Detail**：通过细描边、微光、轻动效表达品质，不靠大面积强渐变堆效果。

## 2. Token 基准

### 2.1 品牌色

| 用途 | CSS 变量 | 值 | 使用说明 |
| --- | --- | --- | --- |
| 品牌主色 / 流光金 | `--brand` / `--brand-400` | `#D4AF37` | 主按钮、选中态、重点图标、关键数值 |
| 香槟金 | `--brand-200` | `#F4E4BC` | 金色渐变浅色端、轻高光 |
| 暗金 | `--brand-600` | `#B8860B` | 金色渐变深色端、强调描边 |
| 品牌渐变 | `--brand-gradient` | `linear-gradient(135deg, var(--brand-200), var(--brand), var(--brand-600))` | 主按钮、职级徽标、品牌标识 |
| 金色柔光 | `--brand-glow` | `rgba(212, 175, 55, 0.15)` | Hover/Active 微光，不要大面积铺满 |
| 品牌弱背景 | `--brand-bg-soft` | `rgba(212, 175, 55, 0.1)` | 选中菜单、淡金色标签 |
| 品牌焦点环 | `--brand-focus-ring` | `0 0 0 3px rgba(212, 175, 55, 0.1)` | 输入框、按钮 focus 态 |

### 2.2 背景与层级

| 层级 | CSS 变量 | 值 | 使用说明 |
| --- | --- | --- | --- |
| 全局背景 | `--surface-0` | `#0A0A0F` | 应用最底层、页面底色 |
| 面板背景 | `--surface-1` | `#16161D` | 侧边栏、顶栏、一级面板 |
| 抬升面 | `--surface-2` | `#1E1E28` | 弹窗、下拉、悬浮面板 |
| 次级抬升面 | `--surface-3` | `#252532` | 列表 hover、局部块 |
| 强抬升面 | `--surface-4` | `#2E2E3C` | 强强调或复杂控件局部背景 |
| 毛玻璃面 | `--glass-card-bg` | `rgba(255, 255, 255, 0.052)` | 卡片和轻面板默认填充 |
| 毛玻璃 hover | `--glass-card-bg-hover` | `rgba(255, 255, 255, 0.074)` | 卡片 hover 填充 |

全局背景允许使用 `--app-page-background`、`--app-ambient-grid`、`--app-ambient-gradient` 形成暗色空间感。不要新增独立的 DOM 光球、装饰性渐变圆点或 bokeh 背景；需要氛围时优先通过已有背景 token 统一控制。

### 2.3 文字

| 层级 | CSS 变量 | 值 | 使用说明 |
| --- | --- | --- | --- |
| 主文字 | `--text-primary` | `#F5F5F7` | 标题、正文主体、重要字段 |
| 次文字 | `--text-secondary` | `#A0A0A8` | 描述、辅助说明、未选中导航 |
| 弱化文字 | `--text-muted` | `#6B6B73` | 占位符、时间戳、禁用态 |
| 金色文字 | `--text-gold` | `var(--brand)` | 强调、价格、统计数值、选中态 |
| 品牌反白文字 | `--text-on-brand` | `#0A0A0F` | 金色渐变按钮/徽标上的文字 |

### 2.4 语义色

| 语义 | CSS 变量 | 值 | 使用说明 |
| --- | --- | --- | --- |
| 成功 | `--success` | `#2ECC71` | 在线、成功、完成 |
| 警告 | `--warning` | `#F39C12` | 待处理、暂停、注意 |
| 危险 | `--danger` | `#E74C3C` | 删除、错误、失败 |
| 信息 | `--info` | `#3498DB` | 链接、提示、信息态 |

语义色用于状态，不替代品牌金。状态标签使用半透明背景变量：`--success-bg`、`--warning-bg`、`--danger-bg`、`--info-bg`。

### 2.5 边框、圆角、阴影

| 类型 | CSS 变量 | 值 / 说明 |
| --- | --- | --- |
| 默认边框 | `--border` | `rgba(255, 255, 255, 0.08)` |
| Hover 边框 | `--border-hover` | `rgba(255, 255, 255, 0.12)` |
| 激活边框 | `--border-active` | `rgba(212, 175, 55, 0.3)` |
| 金色玻璃边框 | `--glass-gold-border` | `rgba(212, 175, 55, 0.34)` |
| 小圆角 | `--radius-sm` | `6px`，小按钮、角标 |
| 中圆角 | `--radius-md` | `8px`，输入框、菜单项 |
| 大圆角 | `--radius-lg` | `12px`，卡片、面板 |
| 超大圆角 | `--radius-xl` | `16px`，弹窗、大块面板 |
| 全圆角 | `--radius-full` | `9999px`，头像、圆形按钮、药丸标签 |
| 金色光晕 | `--shadow-gold` | `0 0 20px rgba(212, 175, 55, 0.15)` |

圆角默认控制在 6px、8px、12px、16px 四档。工作台、列表、表单类页面避免过度圆润。

## 3. 字体系统

字体族使用现有 Tailwind 扩展：

- `font-display`：`PingFang SC`, `Noto Sans SC`, `SF Pro Display`, `sans-serif`
- `font-body`：`PingFang SC`, `Noto Sans SC`, `SF Pro Display`, `sans-serif`
- `font-number`：`SF Mono`, `Roboto Mono`, `ui-monospace`, `monospace`

| 层级 | 字号 | 字重 | 行高 | 用途 |
| --- | --- | --- | --- | --- |
| Display | `32px` | `700` | `38px` | 页面主标题、品牌展示 |
| H1 | `24px` | `600` | `31px` | 模块标题 |
| H2 | `20px` | `600` | `28px` | 区块标题 |
| H3 | `16px` | `600` | `24px` | 卡片标题、列表标题 |
| Body | `14px` | `400` | `22px` | 正文、描述、表单 |
| Caption | `12px` | `400` | `18px` | 标签、辅助文字、时间戳 |
| Micro | `10px` | `500` | `14px` | 职级、小角标 |

数字、价格、计数可使用 `font-number`，关键数值用 `--text-gold`。不要使用负字距；控件内文字必须在桌面和移动宽度下完整可读。

## 4. 间距与布局

采用 4px 基准网格，使用已有间距变量：

| Token | 值 | 用途 |
| --- | --- | --- |
| `--space-1` | `4px` | 图标与文字、紧凑内边距 |
| `--space-2` | `8px` | 控件间距、列表项内小间距 |
| `--space-3` | `12px` | 表单项、标签组 |
| `--space-4` | `16px` | 常规块内边距、列表分组 |
| `--space-6` | `24px` | 卡片内边距、页面分区 |
| `--space-8` | `32px` | 大区块间距 |
| `--space-12` | `48px` | 页面级留白 |
| `--space-16` | `64px` | 首尾安全留白 |

全局框架使用项目变量：`--sidebar-width`、`--sidebar-collapsed-width`、`--panel-width`、`--detail-panel-width`。参考 HTML 中的 240px 侧边栏只作为视觉样板，实际实现以项目变量为准。

## 5. 核心材质

### 5.1 标准毛玻璃面板

```css
.glass-panel {
  background: var(--glass-card-bg);
  backdrop-filter: var(--glass-card-filter);
  -webkit-backdrop-filter: var(--glass-card-filter);
  border: 1px solid var(--glass-card-border);
  border-radius: var(--radius-lg);
  box-shadow: var(--glass-card-shadow);
}
```

### 5.2 金色强调毛玻璃

用于选中面板、推荐卡片、关键业务对象。金色只作为边框、高光、局部数值，不要整块铺金。

```css
.glass-panel.active {
  background: var(--glass-card-bg-hover);
  border-color: var(--glass-card-border-hover);
  box-shadow: var(--shadow-gold);
}
```

### 5.3 悬浮态

卡片、面板 hover 默认：

- `background` 从 `--glass-card-bg` 到 `--glass-card-bg-hover`
- `border-color` 到 `--glass-card-border-hover` 或 `--border-hover`
- 允许 `translateY(-2px)`；人才市场等展示卡可到 `translateY(-4px)`
- 动画时长 `--duration-base` 到 `--duration-panel`

复杂工作台不要让 hover 改变布局尺寸。

## 6. 组件规范

### 6.1 按钮

| 类型 | 样式 | 用途 |
| --- | --- | --- |
| Primary | `--brand-gradient` 背景，`--text-on-brand` 文字，字重 600 | 创建、确认、招募、发送等主操作 |
| Secondary | 透明背景，金色文字，`rgba(212, 175, 55, 0.4)` 边框 | 查看详情、筛选、取消中的强调项 |
| Ghost | 半透明白底，主文字，弱白边框 | 更多、展开、普通次级操作 |
| Danger | `--danger-bg` 背景，`--danger` 文字和边框 | 删除、移除、危险确认 |
| Icon | 36px 或 32px 正方形，线性图标居中 | 工具栏、列表快捷操作 |

按钮尺寸：

- 标准高度：`40px`
- 紧凑高度：`36px`
- 图标按钮：`32px` 或 `36px`
- 圆角：`--radius-md`
- 图标与文字间距：`8px`

交互：

- Hover：主按钮轻微上移并出现 `--shadow-gold`；描边按钮增加淡金背景。
- Active：`transform: scale(0.98)`。
- Focus：使用 `--brand-focus-ring`。
- Disabled：透明度降低到 `0.4`，禁用 hover 光效。

### 6.2 卡片

默认卡片使用毛玻璃材质，结构应包含清晰标题、辅助描述、状态/操作区。卡片不是页面区块的默认包装，只有重复条目、信息对象、弹窗和独立工具才使用卡片。

常见类型：

- **人才卡片**：头像 64px、职级徽标、岗位名称、技能标签、统计数据。
- **任务卡片**：左侧 3px 状态条、运行状态、触发方式、上次执行结果。
- **知识卡片**：文件/知识源图标、类型标签、更新时间、操作入口。
- **消息气泡**：左右方向清晰，接收方用半透明灰面，发送方用淡金或品牌强调面。

Hover：`translateY(-2px)`、边框微金、背景变亮。展示型人才卡 hover 可 `translateY(-4px)`。

### 6.3 侧边栏与导航

导航项目：

- 高度：`44px`
- 圆角：`--radius-md`
- 图标：20px，线宽 1.5 到 2
- 图标与文字间距：`12px`
- 未选中：`--text-secondary`
- Hover：`--text-primary` + `rgba(255,255,255,0.04)` 背景
- Active：`--brand` 文字 + `--brand-bg-soft` 背景 + 左侧 3px 金色指示条

侧边栏背景使用 `--navigation-glass-bg` 或 `--surface-1-glass`，边框使用 `--navigation-glass-border`。收起态必须保留图标识别和 tooltip。

### 6.4 顶栏与搜索

顶栏高度默认 `56px`，背景使用毛玻璃 chrome：`--workspace-topbar-background` 或 `--chrome-glass-bg`。搜索框：

- 高度：34px 到 40px
- 背景：`--input-bg`
- 边框：`--border`
- 圆角：`--radius-md`
- 图标：搜索图标使用 `--text-muted`
- Focus：边框 `rgba(212,175,55,0.5)` + `--brand-focus-ring`

### 6.5 输入框

| 属性 | 规范 |
| --- | --- |
| 高度 | 36px 标准，40px 大号 |
| 背景 | `--input-bg` |
| Focus 背景 | `--input-bg-focus` |
| 边框 | `--border` |
| 圆角 | `--radius-md` |
| 输入文字 | `--text-primary` |
| Placeholder | `--text-muted` |

输入框内可放左侧图标，图标尺寸 16px。错误态用 `--danger`，成功态用 `--success`，不要用品牌金表达校验结果。

### 6.6 徽标与标签

| 类型 | 视觉 | 用途 |
| --- | --- | --- |
| 职级徽标 | 金色渐变 + `--text-on-brand` + 4px 圆角 | L1/L3/L5 等等级 |
| 状态标签 | 半透明语义背景 + 语义色文字 + 6px 状态点 | 在线、忙碌、离线、运行中 |
| 技能标签 | `rgba(255,255,255,0.06)` 背景 + `--text-secondary` | 技能、能力、分类 |
| 计数徽标 | 品牌金或危险红圆点 | 未读、通知、数量 |

标签字号通常为 12px，Micro 徽标可用 10px。药丸标签用 `--radius-full`，职级/角标用 `--radius-sm`。

### 6.7 头像

| 尺寸 | 用途 |
| --- | --- |
| 64px | 员工详情、人才卡片 |
| 40px | 聊天列表、成员列表 |
| 32px | 消息头像、紧凑对象 |
| 24px | 表格、迷你列表 |

AI 员工头像默认可带 `rgba(212,175,55,0.3)` 金色描边。在线点放右下角，8px，成功色；离线使用 `--text-muted`。

### 6.8 弹窗与浮层

- 遮罩：`--overlay-bg` 或 `--overlay-bg-heavy`
- 面板：毛玻璃 + `--shadow-lg`
- 圆角：`--radius-xl`
- 标准宽度：520px
- 宽弹窗：720px
- 超宽弹窗：900px
- 出现：淡入 + `scale(0.95 -> 1)` + `translateY(10px -> 0)`，300ms
- 关闭：淡出 + 轻微缩放，200ms

浮层不要嵌套卡片外观；内部内容用分割线、间距和标题层级组织。

### 6.9 图标

新 UI 统一使用 `lucide-react`，不要手写 SVG。尺寸规范：

- 工具栏/导航：20px
- 小按钮/输入框：16px
- 重点入口/空状态：24px
- 默认线宽：1.5 到 2

图标颜色默认 `--text-secondary`，hover 到 `--text-primary`，active 到 `--brand`。纯图标按钮必须有清晰的 hover/focus 态和可访问名称。

### 6.10 表单提交与保存操作

新建、编辑类表单必须把保存操作设计成明确的主操作，不使用浏览器默认按钮样式或与普通次级操作完全相同的视觉样式。

- 操作区通常放在表单底部，使用上边框和轻微抬升面与表单内容分隔；在长表单中保持操作区易于找到。
- 保存按钮使用 Primary 规范：`--brand-gradient` 或项目统一品牌按钮组件，文字使用 `--text-on-brand`，标准高度 40px，图标与文字间距 8px。
- 保存按钮文案必须表达结果，例如“保存任务”“保存修改”“创建员工”，不要使用含义模糊的“确定”。
- 保存按钮必须有三种可识别状态：默认、保存中、禁用。保存中显示 `LoaderCircle` 等加载图标和“保存中…”文案，禁止重复提交。
- 取消按钮使用 Secondary/Ghost，不得与保存按钮争夺视觉权重；危险操作使用 Danger，不得使用品牌金表示删除或失败。
- 保存成功、失败和冲突必须通过页面内反馈表达；错误提示应靠近操作区或表单顶部，不能只依赖控制台日志。
- 表单按钮必须支持键盘 focus，使用 `--brand-focus-ring`，并保证窄屏下按钮文案不被截断。

### 6.11 业务动作命名与入口语义

按钮文案必须说明实际结果，避免把内部实现概念直接暴露给用户。

- “查看/打开会话”仅用于进入既有关联会话、查看执行过程和结果，不代表立即执行任务；若会触发执行，必须单独命名为“立即执行”。
- “运行记录”用于历史执行状态，不与“会话”混用；没有记录时明确展示“暂无运行记录”。
- 会修改任务配置的入口使用“编辑”，改变生命周期使用“启用/暂停”，删除使用“删除”，并在删除前说明保留历史或不可逆影响。
- 每个动作应尽量使用“动词 + 对象”的短文案，并配合符合语义的 `lucide-react` 图标；图标不能替代不可猜测的关键文案。

## 7. 动效规范

| 动效 | 规范 |
| --- | --- |
| 普通 hover | `--duration-base`，`ease` 或 `--ease-out` |
| 面板展开/收起 | `--duration-panel`，淡入 + 位移 |
| 按钮 active | `scale(0.98)`，快速反馈 |
| 卡片 hover | `translateY(-2px)`，展示卡可 `-4px` |
| AI 输入中 | 三个金色圆点上下跳动，1.4s 循环 |
| 成功反馈 | 小范围金色 pulse，避免大面积闪烁 |

动效服务于状态理解，不制造持续干扰。涉及大量列表或工作台时，优先保证性能和布局稳定。

## 8. 页面级应用规则

1. **先 token，后硬编码**：颜色、圆角、阴影、间距优先用 CSS 变量或 Tailwind token；禁止新页面自行引入 `--accent` 等未纳入设计系统的颜色变量。
2. **深色背景保持层级**：全局背景、侧栏、主内容、浮层需要明确层级，不要所有面都同一个灰度。
3. **金色只用于决策点**：主操作、选中态、关键数据、品牌标识；普通说明和装饰不滥用金色。
4. **毛玻璃要有背后层次**：没有背景层次时不要强行加重 blur，可用轻透明面 + 细边框。
5. **避免卡片套卡片**：页面区块保持开放式布局，卡片只承载具体对象或工具。
6. **复杂交互用独立 CSS**：遵循项目约定，复杂页面不要把大量状态样式堆进 TSX。
7. **工具类按钮优先图标**：常见操作使用 lucide 图标，必要时配 tooltip；主流程按钮可使用图标 + 文案。
8. **状态色独立于品牌色**：成功、警告、错误、信息按语义色表达，不用金色替代。
9. **文本必须稳定可读**：按钮、标签、卡片标题在窄屏和长文案下不能溢出或重叠。
10. **视觉参考不等于复制 HTML**：`docs/design/设计视觉系统参考.html` 是样板，实际实现要遵守项目变量、组件结构和业务密度。
