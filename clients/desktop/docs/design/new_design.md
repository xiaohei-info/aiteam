## 一、系统定位与用户画像

### 1.1 系统定位

AIFred 是一款 **AI 原生组织客户端系统**，面向企业用户提供"AI 员工"管理、协作与编排能力。系统以"虚拟组织"为核心隐喻——用户可以像管理真实团队一样，招募 AI 员工、组建团队、分配任务、编排自动化流程，并在可视化办公室中实时观察 AI 员工的工作状态。

**核心价值主张**：让企业以管理人类团队的方式管理 AI 能力，降低 AI 落地门槛。

### 1.2 用户画像

| 画像维度 | 描述 |
|---------|------|
| **主要用户** | 企业管理者、部门负责人、业务运营人员 |
| **技术背景** | 非技术或轻技术背景，习惯使用企业微信/钉钉/飞书等办公工具 |
| **核心诉求** | 低门槛配置 AI 能力、可视化掌控 AI 工作状态、按需弹性扩缩 AI 员工 |
| **使用场景** | 日常工作编排、知识管理、自动化流程配置、团队协作 |
| **心理预期** | 期望系统专业、可靠、有品质感，能体现场所的高端调性 |

### 1.3 设计理念

> **"数字尊享，智能驭界"** —— 以黑金质感传递企业级专业与尊贵，以毛玻璃层次感营造科技未来感，让每一次交互都如同操作一件精密的高端工具。

## 二、设计风格与视觉语言

### 2.1 风格关键词

**奢华黑金 · 毛玻璃质感 · 深色沉浸 · 金属光泽 · 微动效点缀**

系统整体采用深色沉浸式设计语言，以纯黑/深灰为底，金色为视觉焦点，通过毛玻璃（Glassmorphism）效果营造层次与深度。所有界面元素追求"有重量感的精致"——不是轻飘飘的扁平卡片，而是有阴影、有材质、有光泽的实体感。

### 2.2 风格参考

| 参考方向 | 参考描述 |
|---------|---------|
| **Apple Vision Pro UI** | 深色背景 + 毛玻璃面板 + 精致光影层次 |
| **奢侈品牌官网**（如 LV、Rolex 数字界面） | 黑金配色、serif 标题字体、大面积留白 |
| **Linear / Arc Browser 深色模式** | 深色界面中的微光边框、细腻渐变 |
| **iOS 控制中心** | 毛玻璃卡片层叠、圆角柔和、半透明叠加 |

## 三、设计系统规范

### 3.1 间距系统

采用 **4px 基准网格**，所有间距为 4 的倍数。

| Token | 值 | 用途 |
|-------|-----|------|
| `space-1` | 4px | 图标与文字间距、紧凑内边距 |
| `space-2` | 8px | 按钮内边距、列表项间距 |
| `space-3` | 12px | 卡片内边距、表单项间距 |
| `space-4` | 16px | 区块间距、标准内边距 |
| `space-6` | 24px | 卡片间距、分区间距 |
| `space-8` | 32px | 大区块间距 |
| `space-12` | 48px | 页面级留白 |
| `space-16` | 64px | 顶部/底部安全留白 |

### 3.2 圆角系统

| Token | 值 | 用途 |
|-------|-----|------|
| `radius-sm` | 6px | 小按钮、标签、徽标 |
| `radius-md` | 8px | 输入框、下拉菜单 |
| `radius-lg` | 12px | 卡片、面板 |
| `radius-xl` | 16px | 大卡片、弹窗 |
| `radius-full` | 9999px | 头像、圆形按钮、药丸标签 |

### 3.3 阴影与毛玻璃效果

#### 阴影

| 层级 | 值 | 用途 |
|------|-----|------|
| `shadow-sm` | `0 1px 3px rgba(0,0,0,0.4)` | 卡片基础阴影 |
| `shadow-md` | `0 4px 12px rgba(0,0,0,0.5)` | 悬浮卡片、下拉菜单 |
| `shadow-lg` | `0 8px 32px rgba(0,0,0,0.6)` | 弹窗、模态框 |
| `shadow-gold` | `0 0 20px rgba(212,175,55,0.15)` | 金色高亮元素发光效果 |

#### 毛玻璃效果

```css
/* 标准毛玻璃面板 */
.glass-panel {
  background: rgba(255, 255, 255, 0.05);
  backdrop-filter: blur(20px);
  -webkit-backdrop-filter: blur(20px);
  border: 1px solid rgba(255, 255, 255, 0.08);
  border-radius: 12px;
}

/* 金色边框毛玻璃面板 */
.glass-panel-gold {
  background: rgba(255, 255, 255, 0.05);
  backdrop-filter: blur(20px);
  border: 1px solid rgba(212, 175, 55, 0.2);
  border-radius: 12px;
  box-shadow: 0 0 20px rgba(212, 175, 55, 0.05);
}

/* 悬浮态毛玻璃面板 */
.glass-panel-hover {
  background: rgba(255, 255, 255, 0.08);
  backdrop-filter: blur(20px);
  border: 1px solid rgba(212, 175, 55, 0.3);
  box-shadow: 0 4px 20px rgba(0, 0, 0, 0.4), 0 0 20px rgba(212, 175, 55, 0.1);
}
```

### 3.4 组件规范

#### 3.4.1 按钮

| 类型 | 背景 | 文字 | 边框 | 尺寸（高） | 用途 |
|------|------|------|------|-----------|------|
| **主按钮（金色）** | 渐变 `#F4E4BC → #D4AF37` | `#0A0A0F` | 无 | 36px / 40px | 核心操作：创建、招募、确认 |
| **次按钮（描边）** | `transparent` | `#D4AF37` | `1px solid rgba(212,175,55,0.4)` | 36px / 40px | 辅助操作：取消、筛选 |
| **幽灵按钮** | `rgba(255,255,255,0.05)` | `#F5F5F7` | `1px solid rgba(255,255,255,0.1)` | 36px / 40px | 次要操作：更多、展开 |
| **危险按钮** | `rgba(231,76,60,0.15)` | `#E74C3C` | `1px solid rgba(231,76,60,0.3)` | 36px / 40px | 删除、移除 |

**按钮交互态**：
- Hover：背景亮度 +10%，出现 `shadow-gold`（主按钮）
- Active：缩放 `scale(0.98)`，亮度 -5%
- Disabled：透明度 0.4，禁止光标
- Focus：金色描边外发光 `0 0 0 3px rgba(212,175,55,0.2)`

## 六、动效规范

### 6.1 通用动效原则

| 原则 | 说明 |
|------|------|
| **自然流畅** | 使用 ease / ease-out 曲线，避免线性动画 |
| **层次分明** | 大元素先动，小元素后动，形成视觉节奏 |
| **克制有度** | 动效服务于功能，不过度装饰 |
| **金色点缀** | 关键动效使用金色光效，强化品牌感 |

### 6.2 基础动效

| 动效类型 | 参数 | 用途 |
|---------|------|------|
| **淡入淡出** | `opacity 0→1, 200ms ease` | 页面切换、内容加载 |
| **滑入滑出** | `translateX/Y + opacity, 300ms ease-out` | 面板展开、列表项出现 |
| **缩放出现** | `scale(0.95)→1 + opacity, 250ms ease-out` | 弹窗、卡片 |
| **弹性回弹** | `scale(0.8)→1.05→1, 400ms cubic-bezier` | 新增节点、成功反馈 |
| **指示条滑动** | `translateX, 300ms ease` | Tab 切换、菜单选中 |
| **高度展开** | `height auto, 300ms ease` | 折叠面板、详情展开 |

### 6.3 交互反馈动效

| 交互 | 动效 | 说明 |
|------|------|------|
| **按钮 Hover** | `translateY(-1px)` + `shadow-gold` | 200ms |
| **按钮 Active** | `scale(0.98)` | 100ms |
| **卡片 Hover** | `translateY(-2px)` + 边框金色提亮 + `shadow-gold` | 200ms |
| **列表项 Hover** | 背景色渐变 | 150ms |
| **输入框 Focus** | 边框金色 + 外发光渐现 | 200ms |
| **加载中** | 三点跳动 / 环形旋转 | 金色，无限循环 |
| **成功反馈** | ✓ 图标弹出 + 金色粒子飞散 | 400ms |
| **失败反馈** | 抖动 `translateX(±4px, 3次)` | 300ms |

### 6.4 页面切换动效

| 场景 | 动效 |
|------|------|
| **模块切换**（侧边栏） | 旧内容淡出（150ms）→ 新内容淡入 + 轻微上移（200ms） |
| **详情页打开** | 从右侧滑入面板 + 遮罩淡入 |
| **弹窗出现** | 遮罩淡入（200ms）+ 弹窗 `scale(0.95)→1 + translateY(10)→0`（300ms） |
| **弹窗关闭** | 弹窗 `scale(1)→0.95 + opacity→0`（200ms）+ 遮罩淡出（200ms） |

### 7.3 模块间数据流转

#### 7.3.1 人才市场 → 组织架构

```
人才市场（招募 AI 员工）
    │
    ├──→ 选择目标部门
    │
    ├──→ 调用招募 API
    │    └── 创建员工记录 → 关联到部门节点
    │
    ├──→ 组织架构更新
    │    └── 新增员工节点 → 树状结构刷新
    │
    ├──→ 通讯录更新
    │    └── 可在群聊创建时选择该员工
    │
    └──→ 费用账户
         └── 记录招募费用
```

#### 7.3.2 单聊/群聊 → 员工数据

```
聊天交互
    │
    ├──→ 发送消息 → AI 员工处理
    │
    ├──→ 更新员工统计数据
    │    ├── 召唤次数 +1
    │    ├── 累计费用 += 单次费用
    │    └── 今日工时 += 处理时长
    │
    ├──→ 员工详情面板实时刷新
    │
    ├──→ 办公室场景状态更新
    │    └── 该员工状态 → "执行任务中"
    │
    └──→ 费用统计更新
         └── 今日花费 / 本月花费 递增
```

#### 7.3.3 自动化 → 聊天/办公室

```
自动化任务触发
    │
    ├──→ 按流程步骤调用 AI 员工
    │
    ├──→ 每步骤：
    │    ├── 更新员工统计数据（召唤次数/费用）
    │    ├── 办公室场景：员工状态 → "执行任务中"
    │    └── 任务完成后：员工状态恢复
    │
    ├──→ 执行结果：
    │    ├── 存入知识库（可选）
    │    └── 推送通知到相关群聊（可选）
    │
    └──→ 更新任务执行历史
```

#### 7.3.4 知识库 → 聊天/自动化

```
知识库文件上传
    │
    ├──→ 建立搜索索引
    │    ├── 文件名索引
    │    ├── 内容提取索引
    │    └── 图片 OCR 索引
    │
    ├──→ 聊天模块可用
    │    └── AI 员工可引用知识库内容回答问题
    │
    └──→ 自动化模块可用
         └── AI 员工在自动化流程中可读取知识库文件
```

#### 7.3.5 组织架构 → 全局

```
组织架构变更
    │
    ├──→ 员工移除
    │    ├── 从所有群聊中移除
    │    ├── 通讯录中删除
    │    ├── 办公室场景工位置空
    │    └── 聊天会话标记"已离开"
    │
    ├──→ 员工调动
    │    ├── 通讯录部门更新
    │    └── 办公室场景工位移动
    │
    └──→ 部门变更
         └── 组织架构树刷新
```
