# 办公室元素样板 v1

本批为原图实像素裁切样板，不是生成图，也不是已完成抠图的地图精灵。保留原图的装修、材质、光照和透视，供元素制作时比对。

- `contact-sheet.png`：28 项元素总览，预览中部分小图放大，独立 PNG 保持原始裁切分辨率。
- `crops/`：28 张独立 PNG。
- `source-10-annotated.png`、`source-50-annotated.png`：裁切位置和编号。
- `manifest.json`：元素 ID、中文名称、来源底图编号、左上角像素坐标 `[x, y, width, height]`。
- `generation-prompts.md`：后续补全元素时可用的提示词规格，本批尚未调用生图工具。

来源：`public/assets/office/icon_office_10.png` 和 `icon_office_50.png`。编号 10 取自 50 人底图，其余取自 10 人底图。

## 使用范围

墙角、外窗、玻璃隔断保留周边建筑；会议桌椅、柜台、吧台、花架、卫生间隔间采用组合裁切。独立设备可能包含相邻物体，尤其水槽、冰箱和小型咖啡设备。设备细分类属于视觉推断，不作为产品型号识别。

地板样本没有经过透视校正、去光照或无缝化。窗户和玻璃隔断包含背景，不能直接用矩形透明度代替真实透光素材。原图未显示的背面、底部和其他朝向仍需重建。

## 后续生产顺序

1. 建筑：白墙直段与转角、窗模块、玻璃隔断、门的开关状态。
2. 地板：以 08 / 09 / 10 为纹理参考，制作正交、均匀光照、无缝纹理。
3. 家具：分离植物、座椅、柜台等主体并补全遮挡，校准共同视角与比例。
4. 导出带真实 alpha 的精灵，另外记录占地、落地锚点、朝向、附着点和遮挡层。

本批没有接入办公室运行逻辑，也没有替换现有底图。

复现（macOS，仓库根目录）：`swift scripts/extract-office-samples.swift`。脚本会重新生成本目录的 PNG 和 manifest。
