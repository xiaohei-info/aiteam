AIFred 测试版 — macOS 安装说明

一、安装
1. 将 AIFred.app 拖到旁边的 Applications（应用程序）快捷方式。
2. 等待复制完成，从“应用程序”文件夹打开 AIFred。
3. 如能正常运行，无需执行修复脚本。

二、提示“已损坏”或无法验证开发者时
仅在确认应用由可信开发者提供、文件完整的情况下使用以下步骤。
如系统提示包含恶意软件，请停止安装并联系开发者，不要绕过。

1. 退出 AIFred，确认已完成复制，不要在 DMG 内直接运行应用。
2. 双击此安装盘中的“修复应用无法打开.command”。
3. 在选择窗口中选中“应用程序”文件夹下的 AIFred.app。
4. 核对路径，输入 y 并回车确认清除隔离标记并替换为本地临时签名。
5. 如果提示权限不足，可以确认使用管理员权限重试；输入本机管理员密码时不会显示字符。
6. 只有脚本提示“本地临时签名完整性检查通过”后，再重新打开 AIFred。若签名失败或仍有问题，请将报错和签名检查结果发给开发者。

三、脚本本身被 macOS 拦截或提示没有执行权限
下载的脚本也可能被 macOS 拦截，无法保证首次双击即可执行。
确认来源可信后，可尝试右键脚本 → 打开，或在“系统设置 → 隐私与安全性”查看是否提供“仍要打开”。
如果没有此入口，可先用文本编辑器查看脚本内容，确认可信后：
1. 打开“终端”。
2. 输入 /bin/bash 并在后面加一个空格。
3. 将安装盘中的“修复应用无法打开.command”拖入终端。
4. 按回车执行，并按提示操作。

重要说明
- 此工具移除所选应用的下载隔离属性 com.apple.quarantine，并使用 codesign --force --deep --sign - 替换为本地临时签名。
- 它会修改应用及内嵌代码的现有签名；不会提供 Developer ID 签名、完成 Apple 公证、修复真正损坏的文件或关闭 Gatekeeper。
- 这是尚未完成正式签名、公证的测试版临时方案，不是 Apple 安全认证。
- 不要用它处理来源不明的应用，也不要全局关闭系统安全防护。
