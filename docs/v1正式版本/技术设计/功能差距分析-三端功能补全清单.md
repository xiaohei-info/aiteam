# AI Team v1 三端功能补全清单（差距分析）

> 本文对照旧版 app/ 与 PRD 需求文档，梳理重构后三端服务已具备与缺失的功能。
> 映射口径：PRD 企业前台(P01-P09) -> Agent 端；企业后台(B01-B09) -> Manager 端；系统后台(S01-S04) -> Operation 端。

## 一、Operation Service（运营端）

### 已具备
- 系统登录 POST /api/operation/auth/login
- 企业开通 POST /api/operation/enterprises
- 负责人重置 POST /api/operation/enterprises/{id}/reset
- 人才模板目录 POST/GET /api/operation/catalog/*
- 行业方案目录 POST/GET /api/operation/catalog/*
- 跨企业汇总 POST/GET /api/operation/rollup/*
- 健康检查 GET /ping

### 缺失
- S01 企业列表(搜索/筛选/分页) GET /api/system-admin/enterprises
- S01 企业详情 GET /api/system-admin/enterprises/{id}
- S01 企业导出 GET /api/system-admin/enterprises/export
- S01 企业操作(充值/封禁/通知) POST /api/system-admin/enterprises/{id}/{action}
- S01 统计卡片(总企业数/本月新增/月活/总充值)
- S02 模板完整编辑 PATCH /api/system-admin/templates/{id}
- S03 方案完整编辑 PATCH /api/system-admin/solutions/{id}
- S03 方案应用统计 GET /api/system/solutions/stats
- S04 财务总览 GET /api/system-admin/finance/overview
- S04 财务报表 GET /api/system-admin/finance/reports
- 系统健康 GET /api/system-admin/health

## 二、Manager Service（企业端）

### 已具备
- 成员/负责人登录 POST /api/auth/login
- 负责人首登重置 POST /api/auth/owner-reset
- JWKS GET /api/auth/{tenant_id}/jwks.json
- Bootstrap POST /api/manager/bootstrap
- 部门 CRUD /api/manager/departments
- 成员 CRUD /api/manager/members
- 员工配置 CRUD /api/manager/employees
- 授权 CRUD /api/manager/grants
- 知识空间 CRUD /api/manager/knowledge-spaces
- 能力目录(技能/连接器/记忆) /api/manager/capability/*
- Provider凭据 CRUD /api/manager/provider-credentials
- 招募专家/应用方案 /api/manager/recruit/*
- 快照冻结 POST /api/manager/snapshots/freeze
- 用量审计配额 /api/manager/usage-audit-quota

### 缺失
- B01 员工技能/知识/记忆/连接器绑定
- B01 员工 Prompt 配置
- B01 员工 Runtime 绑定(模型/温度/max_tokens)
- B01 员工导出 CSV
- B01 员工消耗统计
- B02 技能安装/卸载/搜索/版本/权限
- B04 Token消耗总览/记录/导出CSV/趋势/排行
- B05 连接器测试/状态/grants/预设/自定义MCP
- B06 方案列表/预览/已应用状态
- B07 记忆条目 CRUD/搜索/批量删除/按员工查看
- B08 企业设置/子管理员邀请
- B09 账户余额/充值记录/充值
- 组织树 GET /api/manager/org/tree
- 员工部门分配 PATCH /api/manager/org/assignments/{id}
- LLM Provider列表/Model列表/Model增删/Provider编辑删除
- 协作模板 GET/PUT /api/manager/collaboration-template
- 审计事件 GET /api/manager/audit-events

## 三、Agent Service（用户端）

### 已具备
- 本地登录 POST /api/agent/login
- 会话/消息/Run /api/agent/* (mainline)
- 群聊基础 /api/agent/groups/*
- Loop /api/agent/loops/*
- 授权同步 /api/agent/grants/*
- Usage 上报 /api/agent/usage/*

### 缺失
- P02 工作台视图/状态
- P03 人才市场列表/专家详情/招募
- P05 员工对话列表/文件上传
- P06 群聊完整(创建/成员/消息/归档/更新)
- P07 组织树本地投影
- P08 知识库列表/搜索/文档上传
- P09 办公室场景/动态

## 四、前端缺失

### Operation: 缺 accounts/templates完整编辑/solutions完整编辑/finance/system-health
### Manager: 缺 billing/recharge/settings/org-chart/collaboration/audit/memory-items/connector-detail/solution-apply
### Agent: 缺 marketplace/office/workbench/knowledge/org-chart/template-detail

## 五、并行编排

### Wave 1: Manager 端 (最关键)
- M-billing: 工资管理+充值+余额
- M-employee-config: 员工绑定(技能/知识/记忆/连接器/Prompt/Runtime)
- M-connector: 连接器测试/状态/grants
- M-memory: 记忆条目CRUD
- M-solution: 方案列表/预览
- M-org: 组织树/部门分配
- M-llm: LLM Provider/Model管理
- M-settings: 企业设置/邀请
- M-audit: 审计事件
- M-collab: 协作模板

### Wave 2: Operation 端
- O-accounts: 企业列表/详情/操作/导出/统计
- O-templates: 模板完整编辑
- O-solutions: 方案完整编辑/统计
- O-finance: 财务总览/报表/趋势
- O-health: 系统健康

### Wave 3: Agent 端
- A-workbench: 工作台视图/状态
- A-marketplace: 人才市场浏览/招募
- A-office: 办公室场景/动态
- A-knowledge: 知识库列表/搜索/上传
- A-group-full: 群聊完整
- A-org: 组织树本地投影
- A-upload: 文件上传
