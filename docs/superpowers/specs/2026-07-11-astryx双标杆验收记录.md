## Cost

- 计量方式：生产构建后对单入口 JS/CSS 使用 `gzip -c | wc -c`；before 为基线提交 `3c3d3ce7`，after 为双标杆分支当前产物。
- Manager bundle delta：100,696 B → 206,408 B，增加 105,712 B（+104.98%）。
- Agent bundle delta：87,015 B → 198,995 B，增加 111,980 B（+128.69%）。
- 解释与接受：两端增量主要来自首次引入 Astryx Core、Stone、StyleX 运行时及官方 CSS cascade，属于一次性的设计系统基础成本；后续页面复用同一基础层，不应按页面重复增加同等成本。该增量超过 25%，按 Astryx 方案已获确认并继续实施的前提接受为 rollout baseline；后续只基于实测做分包/按需加载，不在标杆阶段投机优化。
