# AI Team 完整产品交付路线图

> 用户确认：以本文作为 AI Team 完整产品交付的唯一执行目标；当前优先收口 taiyi 测试环境，再完成生产级 hardening。本文只记录交付任务和验收，不改变 v1 架构边界。

## 1. 交付定义

完整交付不是“服务能启动”，而是同时满足：

1. Operation / Manager / Agent 三端产品功能可用；
2. Agent 以 Pi 原生 Session/prompt/tool/event/abort 为执行事实源；
3. 企业知识由 Manager + LightRAG 管理，Agent 只经受控 MCP 查询；
4. Memory 由受控 `@luxusai/pi-hindsight` Extension 使用 Manager-scoped Hindsight；
5. Provider/Skill/Attachment/Sandbox/Usage/治理链路完整；
6. taiyi cross-tier E2E 全量通过；
7. 生产部署具备密钥、备份、恢复、升级、监控和回滚能力；
8. 不违反本仓库红线：无旧 Python Agent/Gateway、多 runtime、Run/Task/Loop/DAG 执行模型、Agent 内容上行或跨端直写。
